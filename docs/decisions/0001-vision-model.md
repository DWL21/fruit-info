## 결정
- `codex exec -m gpt-6.1-sol --output-schema`로 분석한다. 업로드 즉시 보여줄 필요가 없어 단일 정밀 단계로 간다.
- 이미지 속 글자를 통한 프롬프트 인젝션에 대비해 셸·브라우저·플러그인·MCP 등 도구를 모두 끄고(`--disable shell_tool ...`, `--ignore-user-config`) 빈 임시 폴더에서 읽기 전용 샌드박스로 실행한다. 도구가 꺼진 상태를 확인했다(명령 실행 요청에 `NO_TOOLS` 응답).
- 출력은 Zod로 검증하고, 품목명은 표준 품목 사전으로 정규화한다.
- `eval/`의 실제 시장 사진으로 주기적으로 재측정한다.
